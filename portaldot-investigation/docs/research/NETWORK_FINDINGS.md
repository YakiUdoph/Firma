## Errors and environment limitations

1. The initial sandboxed curl attempt could not connect and returned curl error 7. Retrying the same endpoint with network permission succeeded. This was an execution-environment limitation, not evidence that Portaldot was down.
2. An inline PowerShell/curl JSON attempt reached the server but lost quoting at the process boundary; the server correctly returned `-32700 Parse error`. Supplying JSON from a file fixed it.
3. The first local metadata decoder run failed with Windows sandbox `EPERM` while resolving the workspace path. Running the local decoder with filesystem permission succeeded.
4. Polkadot JS warned that the custom signed extensions `AuthorizeCall` and `EthSetOrigin` were unknown and treated as no-effect for decoding. Reads succeeded, but this is a material warning for any future signing implementation.
5. EVM `rpc_modules` is not exposed, so method support was established by individual calls rather than module enumeration.
