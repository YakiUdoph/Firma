Scope and safety

        
Verification, not custody.

      

      

        
FIRMA reads public network state. It has no authentication, wallet connection, signing flow, transaction submission, transfer capability, or private-key handling.

        

          Technical scope
          
The verifier fingerprints the runtime, reads Assets and Revive storage, maps the EVM address to its native account, and performs ERC-20-compatible eth_call reads at the same finalized height. Exact base-unit values remain arbitrary-precision integers. Results describe only the listed observations at that block and are not an audit of write behavior.
