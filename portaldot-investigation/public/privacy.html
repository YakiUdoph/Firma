What FIRMA processes when you verify evidence.

Effective date: October 26, 2026

Project identity and privacy contact

This notice is provided for FIRMA, the public project identity. FIRMA is a project name; this notice does not describe it as an incorporated company or registered legal entity.

Privacy questions may be sent to justremotegigs@gmail.com.

Information you provide

A normal verification sends the asset ID and public 0x account address you enter to FIRMA's verification API. Checking an existing report sends the complete selected JSON report and any optional expected commitment to FIRMA's report-check API.

Public blockchain addresses can still be associated with people or activity. Never upload a private key, seed phrase, password, wallet backup, or report containing secrets.

How the information is used

The APIs validate the request and query the configured Portaldot V3 Substrate and EVM RPC providers. Those providers can observe the requested asset, account-related query data, block heights, request timing, and the server's network address.

FIRMA uses an IP-derived client key in temporary function memory for rate limiting. Operational diagnostics contain a request ID, stage durations and outcomes, verdict counts, and bounded failure categories. They are designed not to contain report contents or raw provider error messages.

Storage, cookies, and third parties

  • FIRMA has no application database.
  • No application analytics, advertising trackers, cookies, localStorage, or sessionStorage use was found in the reviewed code.
  • The browser keeps current results in page memory. It writes an evidence file only when you choose Export evidence and writes to the clipboard only when you choose Copy JSON.
  • The hosting provider and RPC providers may process and retain request or operational logs under their own policies.

Third-party policy limits

FIRMA cannot currently state the hosting provider's or RPC providers' exact retention periods, processing regions, or internal access rules. No incorporated legal entity, jurisdiction, retention guarantee, deletion guarantee, or regulatory-compliance claim is stated or implied.
